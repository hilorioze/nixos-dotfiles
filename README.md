# nixos-dotfiles

A public repository for a project containing my personal NixOS and Home Manager configurations for my machines, users, and infrastructure.

> [!NOTE]
> This repository is built only for my personal machines and infrastructure. As a result, some code may be outdated, experimental, or far from ideal, and therefore it is intended only as a reference or example, but not as any kind of template.

**Highlights**:

- Multiple **NixOS** and **Home Manager** configurations for my **workstations**, **servers**, and **users**
- **Multi-architecture** support for **x86_64** and **aarch64**
- Modular **[configuration structure](#configuration-layout)** with shared reusable features and per-host user overrides
- Fully **declarative** self-hosted infrastructure with **Headscale**, **Authentik**, **[mailserver](https://gitlab.com/simple-nixos-mailserver/nixos-mailserver)**, **Traefik**, and a lot of other services
- **Monitoring** driven by a stack of **Grafana**, **Prometheus**, **Loki**, **[Gatus](https://github.com/TwiN/gatus)** and **Alertmanager**
- **[CI-driven deployments](/.github/workflows/manual-deploy.yaml)** via **[deploy-rs](https://github.com/serokell/deploy-rs)**, powered by the **tailnet** and a self-hosted **[niks3](https://github.com/Mic92/niks3)** binary cache
- **Secrets** via **[sops-nix](https://github.com/Mic92/sops-nix)**, encrypted with **age**
- **[Custom rescue ISO](/hosts/hisonix)**
- **[devenv](https://devenv.sh/)** development shell with **treefmt**, **pre-commit hooks**, and **helper scripts**

## Configuration layout

Conceptual layout of the project:

```
/
├── flake.nix                              # Flake entrypoint (inputs, systems, and deploy-rs configs)
├── hosts/                                 # NixOS configurations
│   ├── common/                            # Shared reusable base system configurations
│   │   ├── default.nix                    # Base system entrypoint
│   │   ├── secrets.yaml                   # Global system sops-encrypted secrets
│   │   ├── users/                         # Shared system users
│   │   │   ├── default.nix
│   │   │   └── <user>.nix
│   │   └── features/                      # Reusable system features
│   │       ├── default.nix
│   │       └── <feature>.nix
│   └── <host>/                            # Host-specific configurations
│       ├── default.nix
│       ├── facter.json                    # Hardware report (only for servers, generated by `nixos-facter`)
│       ├── secrets.yaml                   # Host-specific system sops-encrypted secrets
│       ├── ssh_host_ed25519_key.pub       # Public SSH key of the host
│       ├── features/                      # Features explicitly customized by this host
│       │   ├── default.nix
│       │   └── <feature>.nix
│       └── users/                         # Host-specific user accounts
│           ├── default.nix
│           └── <user>.nix
├── home/                                  # Home Manager configurations
│   ├── common/                            # Shared reusable base user configurations
│   │   ├── default.nix
│   │   ├── features/                      # Reusable user features
│   │   │   ├── default.nix
│   │   │   └── <feature>.nix
│   │   └── hosts/                         # Host-specific shared user configurations
│   │       └── <host>/
│   │           ├── default.nix
│   │           └── features/
│   │               ├── default.nix
│   │               └── <feature>.nix
│   └── <user>/                            # User-specific configurations
│       ├── default.nix
│       ├── secrets.yaml                   # Global user sops-encrypted secrets
│       ├── features/                      # Features explicitly customized for this user
│       │   ├── default.nix
│       │   └── <feature>.nix
│       └── hosts/                         # Host-specific user overrides
│           └── <host>/
│               ├── default.nix
│               ├── secrets.yaml           # Host-specific user sops-encrypted secrets
│               └── features/              # Features explicitly customized for this user on this host
│                   ├── default.nix
│                   └── <feature>.nix
├── modules/                               # Custom NixOS and Home Manager modules
│   ├── nixos/
│   │   ├── default.nix
│   │   └── <module>.nix
│   └── home-manager/
│       ├── default.nix
│       └── <module>.nix
├── overlays/                              # Custom Nixpkgs overlays and package patches
│   ├── default.nix
│   └── <overlay>/
│       └── default.nix
└── packages/                              # Custom package definitions
    ├── default.nix
    └── <package>/
        └── default.nix
```
